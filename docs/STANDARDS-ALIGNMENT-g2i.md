## 适用性与保留边界

本 Skill 服务团队反复执行的商品图片策划和迭代，不增加相邻视频、通用插画或店铺运营功能。预期收益是复用事实／图片映射、确认和反馈恢复；没有测量使用频次、工时或 ROI，不编造收益数字。沿用已验证的分阶段方法、固定场景和失败记录，改进现有技能而非新增一套工具工程。

仅指定的两个 MCP 可以生成图片，是用户明确的业务要求；新版规范“不强制配套 Server”不取消该要求。文字策划不依赖服务安装，生成时只需一个支持当前任务的指定服务；不增加其他 Server、全局安装或扩展策划工具依赖。
